# Klepa Up — Telegram-бот + Mini App

Структура: `server.js` (бот + API + раздача приложения), `public/` (мини-приложение: `index.html`, `css/`, `js/`, `assets/`), `render.yaml`, `.env.example`.

## Запуск на Render
1. Загрузите папку в GitHub-репозиторий.
2. Render → New → Blueprint → выберите репозиторий (создаст сервис и базу Postgres).
3. Заполните переменные: `BOT_TOKEN`, `BOT_USERNAME`, `OPENROUTER_KEY`, `PUBLIC_URL` (адрес сервиса на onrender.com).
4. В @BotFather: Bot Settings → Configure Mini App (или /newapp) → укажите `PUBLIC_URL`; Main App нужен для реферальных ссылок `t.me/бот?startapp=ref_ID`.
5. **Добавьте бота администратором в канал @KlepaUp** — иначе он не сможет проверять подписку приглашённых.

Токены храните только в переменных окружения Render, не в коде и не в чате.

## Возможности
- Реферальная ссылка у каждого игрока; награда 1000 ⭐ начисляется, когда приглашённый подписался на @KlepaUp.
- Общий чат, профили (галочка, должность, номер, список подарков), бан.
- Поддержка с админом (в приложении и командой /support), отзывы (в приложении, /review, /reviews).
- Админ-панель (Профиль → Админ-панель): игроки с балансом и NFT (обновление каждые 5 с), выдача звёзд и NFT, промокоды, галочки, должности, права админов, ответы в поддержке.
- ИИ-помощник работает через сервер: ключ OpenRouter не попадает в браузер.

Бесплатная база Render живёт 30 дней — для постоянной работы возьмите платный план или внешний Postgres (Neon, Supabase) в `DATABASE_URL`.
