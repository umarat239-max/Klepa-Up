# Klepa Up — Telegram-бот + Mini App

Готовый проект: бот, сервер, база и мини-приложение. Всё лежит отдельными файлами.

```
server.js          бот (webhook) + API + раздача приложения
package.json       зависимости (express, pg)
render.yaml        автонастройка Render (сервис + база Postgres)
.env.example       список переменных окружения
public/
  index.html       мини-приложение
  css/app.css      стили приложения      css/extra.css  стили чата, админки
  js/app.js        логика приложения      js/extra.js    чат, профили, поддержка, отзывы, админ-панель, обнуление
  assets/          шрифты и картинки
```

## Как загрузить на GitHub
1. Распакуйте архив. На github.com создайте репозиторий (New repository).
2. Add file → Upload files → перетащите **всё содержимое папки** `klepa-bot` (включая `public`, `.gitignore`, `.env.example`) → Commit.

## Как запустить на Render
1. Render → New → **Blueprint** → выберите репозиторий. Создадутся сервис и база Postgres.
2. Заполните переменные:
   - `BOT_TOKEN` — токен от @BotFather
   - `OPENROUTER_KEY` — ключ OpenRouter
   - `PUBLIC_URL` — адрес сервиса, например `https://klepa-up.onrender.com`
   - `BOT_USERNAME` — не обязателен, бот определит себя сам
3. В @BotFather: `/newapp` (или Bot Settings → Configure Mini App) → укажите `PUBLIC_URL`. Для реферальных ссылок `t.me/бот?startapp=ref_ID` сделайте это приложение главным (Main App).
4. **Добавьте бота администратором в канал @KlepaUp** — иначе подписку приглашённых не проверить.
5. Сервер сам ставит webhook, кнопку меню и команды бота. Откройте бота и нажмите /start.

Токены хранятся только в переменных Render, в код и в чат их вставлять нельзя.

## Что умеет
- **Рефералка:** у каждого своя ссылка; 1000 ⭐ пригласившему, когда приглашённый подписался на @KlepaUp.
- **Общий чат** с профилями (аватар, галочка, должность, номер, список подарков), бан, удаление сообщений модераторами.
- **Поддержка** с админом (в приложении и `/support`) и **отзывы** (в приложении, `/review`, `/reviews`).
- **Админ-панель** (Профиль → Админ-панель), обновляется каждые 5 секунд:
  игроки с юзом, балансом, NFT и пометкой онлайн; выдача звёзд и NFT; промокоды (звёзды, NFT, лимит); бан; галочка; должности; права админов; ответы в поддержке; журнал действий админов.
- **Обнуление аккаунта:**
  - админ с правом «Обнуление» (владелец — всегда): карточка игрока → «Обнулить аккаунт». Звёзды возвращаются к 100, подарки и использованные промокоды сбрасываются, у игрока приложение обнуляется при следующем открытии. Роли, бан и реферальная статистика сохраняются.
  - игрок сам: Профиль → «Обнулить мой аккаунт» (два подтверждения).
- ИИ-помощник работает через сервер: ключ OpenRouter не попадает в браузер.

## Важно знать
- Владелец — `ADMIN_IDS` (по умолчанию 1424001997), несколько id через запятую.
- Баланс и инвентарь игрока хранятся в приложении (как в вашей версии), сервер получает их снимок каждые 15 с для админ-панели. Звёзды и NFT от админа, промокодов и рефералов начисляет сервер.
- Бесплатная база Render живёт 30 дней. Для постоянной работы возьмите платный план или внешний Postgres (Neon, Supabase) и вставьте его адрес в `DATABASE_URL`.
- Без `DATABASE_URL` сервер пишет данные в файл `data.json` (удобно для теста, на Render такие данные пропадают при перезапуске).
- Локальный запуск: `npm install`, затем `BOT_TOKEN=... PUBLIC_URL=... node server.js`.
